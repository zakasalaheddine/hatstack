Use the **three-approaches** skill to plan this marketing & ads work.

Interrogate the request before writing — the concrete instance behind the ask, who is affected, what success looks like as a number, the hard constraints, what was already tried. Ask one or two at a time.

Write the plan to `.hatstack/plans/<slug>.md` and record its path in `.hatstack/active-plan`. It needs three `## Approach N` sections (genuinely distinct in strategy), each with **Pros**, **Cons**, **Reversibility**, **Cost** — all four are enforced. If only two genuine strategies exist, add a `## Constrained space` section naming the disqualified third.

Crucially, include a `## Success criteria` section with observable `- [ ]` checkboxes: the accept gate blocks writing campaign assets until at least one exists, and the reviewer — never you — ticks them against the produced work.

Then present the approaches with `AskUserQuestion` and **stop**. Write `APPROVED: <approach> — <date>` only when the human answers. Never write it yourself.
